## Рішення при злитті

- Go, Dockerfiles та інструкції узгоджено на upstream Go 1.27.4.
- У конфігурації збережено одночасно upstream `sysutil` та персональну політику `privacy`.
- Чотири стандартні Docker Compose файли залишаються видаленими; використовується `deploy/docker-compose.personal.yml`.
- Політика приватності, очищення назв Gemini-кешу та збереження налаштувань image generation при міграції 246 залишаються чинними.
- Новий внутрішній MCP роутер отримує той самий middleware приватності та санітизоване відновлення після panic. Тести MCP використовують виробничий конструктор внутрішнього роутера; окремий регресійний тест перевіряє заборонені маршрути.
- У sidebar збережено приховування Plugins/Risk Control, додано upstream MCP з його feature flag.
- Час оновлення OpenAI залишається часом спостереження upstream, з перевіркою ненульового timestamp.
- Тести доступності Prompt Audit / Risk Control узгоджено з навмисним приховуванням цих сторінок у персональній версії.
- Новий тест вбудованих сторінок адаптовано до персональної політики: iframe та зовнішнє посилання не передають `user_id` або session token.

## Antigravity: каталог з оригінального upstream

За уточненням користувача відкинуто персональний каталог із шести моделей:

- backend default mapping і список тестових моделей акаунта відповідають оригінальному upstream;
- frontend Antigravity models і preset mappings взято з upstream (51 модель на цьому commit);
- експорт OpenCode знову містить окремі Claude та Gemini конфігурації upstream;
- видалено персональне джерело `antigravityModels.ts`; backend-тести доступних моделей відновлено з оригінального upstream;
- відповідні тести створення акаунта, whitelist та експорту взято з upstream.

Персональні OpenAI suggestions і mappings збережено. Наявні мапінги в БД не переписуються: це злиття коду та стандартних налаштувань, без звернення до production.
